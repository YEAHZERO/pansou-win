# PanSou 搜索源配置说明

## 问题分析

您反馈部署后搜索结果很少，经过分析发现：

### 当前配置问题
1. ❌ **缺少 Telegram 频道配置**：`start.bat` 中没有设置 `CHANNELS` 环境变量
2. ⚠️ **插件数量较少**：只启用了 19 个插件，系统共有 78 个可用插件

### 搜索源类型
PanSou 支持两种搜索源：
- **Telegram 频道**：通过 `CHANNELS` 环境变量配置
- **搜索插件**：通过 `ENABLED_PLUGINS` 环境变量配置

## 使用方法

### 1. 重启服务

```batch
# 停止当前运行的 pansou.exe（按 Ctrl+C）
# 然后重新运行
start.bat
```

### 2. 查看启动日志

启动后应该看到类似输出：

```

默认并发数: 57 (= 频道数15 + 插件数32 + 10)
缓存已启用: 路径=C:\Users\Administrator\pansou\cache, 最大大小=300MB, TTL=90分钟
异步插件已启用: 响应超时=5秒, 最大工作者=12, 最大任务=60
已启用指定插件 (32个):
  - pioz (优先级: 3) ⭐ 优先搜索
  - labi (优先级: 1)
  - zhizhen (优先级: 1)
  ...
```

### 3. 测试搜索

```bash
# 登录
curl -X POST http://localhost:8889/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 搜索（使用返回的 token）
curl -X POST http://localhost:8889/api/search \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your-token>" \
  -d '{"kw":"速度与激情"}'
```

## 常见问题

### Q: 为什么之前没有配置 Telegram 频道？

A: 之前的配置可能是为了快速测试插件功能，没有添加 Telegram 频道配置。现在已经补充完整。

### Q: 搜索还是很慢怎么办？

A: 
1. 第一次搜索需要从各个源获取数据，会比较慢（5-8秒）
2. 第二次搜索相同关键词会使用缓存，速度很快（<1秒）
3. 可以适当减少频道和插件数量
4. 可以增加 `CONCURRENCY` 并发数

### Q: 某些插件搜索失败？

A: 
1. 部分插件可能需要代理访问
2. 部分网站可能临时不可用
3. 可以在 `start.bat` 中配置代理：`set PROXY=socks5://127.0.0.1:1080`

### Q: pioz 插件没有结果？

A: pioz.cn 是前端渲染网站，需要根据实际 API 调整代码。详见 `plugin/pioz/README.md`
