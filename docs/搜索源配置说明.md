# PanSou 搜索源和插件配置指南

> **完整的搜索源配置说明，包括 Telegram 频道和插件配置**

---

## 📋 搜索源类型

PanSou 支持两种搜索源：
- **Telegram 频道**：通过 `CHANNELS` 环境变量配置
- **搜索插件**：通过 `ENABLED_PLUGINS` 环境变量配置

---

## 🔧 插件类型概览

### 1. 简单插件（无需配置）
这类插件直接爬取公开网站，无需登录或配置，开箱即用。

**示例**：labi, zhizhen, shandian, duoduo, muou, wanou, hunhepan, jikepan, pansearch, panta, qupansou, hdr4k, pan666, susu, thepiratebay, xuexizhinan, panyq, ouge, huban 等

**特点**：
- ✅ 无需任何配置
- ✅ 在 `start.bat` 中添加到 `ENABLED_PLUGINS` 即可使用
- ✅ 自动搜索公开资源

### 2. 高级插件（需要配置）
这类插件需要登录账号或配置参数，提供更丰富的搜索结果。

**示例**：gying, qqpd, weibo

---

## ⚙️ 简单插件配置

### 在 start.bat 中启用

只需在 `ENABLED_PLUGINS` 中添加插件名称即可：

```batch
set ENABLED_PLUGINS=labi,zhizhen,shandian,duoduo,muou,wanou,hunhepan,jikepan,pansearch,panta,qupansou,hdr4k,pan666,susu,thepiratebay,xuexizhinan,panyq,ouge,huban
```

## 🔐 高级插件配置

### 1. gying 插件（光影资源搜索）

**功能**：搜索光影网站的影视资源

**配置步骤**：

#### 步骤1：启用插件
```batch
set ENABLED_PLUGINS=gying,其他插件...
```

#### 步骤2：启动服务后访问配置页面
```
http://localhost:8888/gying/你的用户名
```

#### 步骤3：在网页上登录
1. 输入光影网站的用户名和密码
2. 点击"登录"按钮
3. 登录成功后，插件会自动保存登录状态

#### 步骤4：测试搜索
在配置页面的"测试搜索"区域输入关键词测试

**特点**：
- ✅ 支持多账号（最多10个）
- ✅ 自动保存登录状态（121天有效期）
- ✅ 绕过反爬虫机制
- ✅ Web界面管理

---

### 2. qqpd 插件（QQ频道搜索）

**功能**：搜索QQ频道中的资源分享

**配置步骤**：

#### 步骤1：启用插件
```batch
set ENABLED_PLUGINS=qqpd,其他插件...
```

#### 步骤2：访问配置页面
```
http://localhost:8888/qqpd/你的QQ号
```

#### 步骤3：扫码登录
1. 页面会显示QQ登录二维码
2. 使用手机QQ扫描二维码
3. 扫码后自动检测登录状态

#### 步骤4：配置频道列表
在"频道管理"区域添加QQ频道号，每行一个：
```
pd97631607
kuake12345
languan8K115
```

#### 步骤5：保存并测试
点击"保存频道配置"，然后在"测试搜索"区域测试

**特点**：
- ✅ 支持多账号（最多10个）
- ✅ 扫码登录，安全便捷
- ✅ 支持多个频道（自动去重）
- ✅ 智能分配任务到不同账号

## 📊 插件数据存储

### 简单插件
- 无需存储用户数据
- 只使用内存缓存搜索结果

### 高级插件
所有高级插件的用户数据都存储在：
```
{CACHE_PATH}/插件名_users/
```

例如：
- gying: `cache/gying_users/`
- qqpd: `cache/qqpd_users/`
- weibo: `cache/weibo_users/`

---

## 🎯 插件优先级

插件优先级决定搜索结果的排序，数字越小优先级越高：

```go
plugin.NewBaseAsyncPlugin("labi", 1)      // 优先级 1（最高）
plugin.NewBaseAsyncPlugin("gying", 3)     // 优先级 3
plugin.NewBaseAsyncPlugin("qqpd", 3)      // 优先级 3
plugin.NewBaseAsyncPlugin("weibo", 3)     // 优先级 3
```

在搜索结果中，优先级高的插件结果会排在前面。

## 使用方法

### 1. 重启服务

```batch
# 停止当前运行的 pansou.exe（按 Ctrl+C）
# 然后重新运行
start.bat
```

### 2. 查看启动日志

启动后应该看到类似输出：

```

异步插件已启用: 响应超时=5秒, 最大工作者=12, 最大任务=60
已启用指定插件 (32个):
  - pioz (优先级: 3) ⭐ 优先搜索
  - labi (优先级: 1)
  - zhizhen (优先级: 1)
  ...
```

### 3. 测试搜索

```bash
# 登录
curl -X POST http://localhost:8889/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 搜索（使用返回的 token）
curl -X POST http://localhost:8889/api/search \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your-token>" \
  -d '{"kw":"速度与激情"}'
```

## 常见问题

### Q: 为什么之前没有配置 Telegram 频道？

A: 之前的配置可能是为了快速测试插件功能，没有添加 Telegram 频道配置。现在已经补充完整。

### Q: 搜索还是很慢怎么办？

A: 
1. 第一次搜索需要从各个源获取数据，会比较慢（5-8秒）
2. 第二次搜索相同关键词会使用缓存，速度很快（<1秒）
3. 可以适当减少频道和插件数量
4. 可以增加 `CONCURRENCY` 并发数

### Q: 某些插件搜索失败？

A: 
1. 部分插件可能需要代理访问
2. 部分网站可能临时不可用
3. 可以在 `start.bat` 中配置代理：`set PROXY=socks5://127.0.0.1:1080`

### Q: pioz 插件没有结果？

A: pioz.cn 是前端渲染网站，需要根据实际 API 调整代码。详见 `plugin/pioz/README.md`
