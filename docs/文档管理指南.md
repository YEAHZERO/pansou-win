## 🔄 自动更新机制

### 工作原理

PanSou 使用 **Kiro Agent Hooks** 实现文档索引的自动更新：

```
文档变化 → 触发 Hook → Agent 自动处理 → 更新 README.md
```

### Hook 配置

#### 1. 文档修改时自动更新

**文件**: `.kiro/hooks/update-docs-readme.json`

**触发条件**: 当 `docs/*.md` 或 `docs/*.txt` 被修改时

**执行操作**:
1. 扫描 docs 目录中的所有文档
2. 按照 8 大分类重新组织
3. 更新 docs/README.md 中的：
   - 文档分类表格
   - 场景导航
   - 文档统计
   - 更新记录
4. 保持结构和格式不变
5. 确保所有链接正确

#### 2. 新文档自动归类

**文件**: `.kiro/hooks/update-docs-readme-on-create.json`

**触发条件**: 当在 `docs/` 目录中创建新文档时

**执行操作**:
1. 识别新创建的文档
2. 根据内容和标题判断所属分类
3. 将新文档添加到对应分类表格
4. 设置合适的推荐指数
5. 更新文档统计
6. 在更新记录中添加说明

#### 3. 主目录文档自动移动 ⭐

**文件**: `.kiro/hooks/move-docs-to-folder.json`

**触发条件**: 当在主目录（根目录）创建 `.md` 或 `.txt` 文件时

**执行操作**:
1. 识别新创建的文档（排除 README.md 等特殊文件）
2. 自动移动到 docs 目录
3. 删除主目录下的原文件
4. 触发文档自动归类流程
5. 更新 docs/README.md
6. 通知用户文件已移动

**排除文件**:
- README.md（项目主文档）
- LICENSE（许可证）
- CHANGELOG.md（变更日志）
- 其他特殊配置文件

## ✍️ 新增文档流程

### 方法一：自动归类（推荐）

1. **创建文档**
   ```batch
   REM 方式一：直接在 docs 目录中创建
   notepad docs\新功能说明.md
   
   REM 方式二：在主目录创建（会自动移动到 docs）⭐
   notepad 新功能说明.md
   ```

2. **保存文档**
   - 如果在 docs 目录创建：Hook 会自动触发归类
   - 如果在主目录创建：Hook 会自动移动到 docs 并归类
   - Agent 会自动分析文档内容
   - 自动归类到合适的分类
   - 自动更新 README.md

3. **验证更新**
   ```batch
   REM 查看文件是否已移动到 docs
   dir docs\新功能说明.md
   
   REM 查看 README.md 是否已更新
   type docs\README.md
   ```

### 方法二：手动归类

1. **创建文档**
   ```batch
   notepad docs\新功能说明.md
   ```

2. **编辑 README.md**
   - 打开 `docs/README.md`
   - 找到合适的分类表格
   - 添加新文档条目：
     ```markdown
     | [新功能说明.md](新功能说明.md) | 新功能的详细说明 | ⭐⭐⭐⭐ | 使用新功能 |
     ```

3. **更新统计**
   - 更新文档统计表格
   - 更新更新记录

## 🔧 修改文档流程

### 自动更新（推荐）

1. **修改文档**
   ```batch
   REM 编辑现有文档
   notepad docs\插件开发指南.md
   ```

2. **保存文档**
   - 保存后，Hook 会自动触发
   - Agent 会重新扫描文档
   - 自动更新 README.md（如果需要）

3. **验证更新**
   - 检查 README.md 的更新记录
   - 确认分类和链接正确

### 手动更新

如果只是小修改，不需要更新 README.md：

1. 直接修改文档内容
2. 保存即可
3. README.md 保持不变

## 🛠️ 手动更新索引

### 使用更新工具

```batch
REM 运行更新工具
update-docs-index.bat
```

**工具功能**：
- 统计文档数量
- 显示文档列表
- 显示当前分类统计
- 提供更新说明

### 使用 Kiro Agent

在 Kiro 中执行：

```
更新 docs/README.md 的文档索引，扫描所有文档并重新分类
```

Agent 会自动：
1. 扫描 docs 目录
2. 分析每个文档
3. 重新组织分类
4. 更新 README.md

## 📝 文档编写规范

### 文件命名

- ✅ 使用中文名称（便于理解）
- ✅ 使用描述性名称
- ✅ 避免特殊字符
- ✅ 使用 `.md` 或 `.txt` 扩展名

**示例**：
```
✅ 新增插件和重新部署流程.md
✅ pioz插件实现说明.md
✅ Windows快速开始.md
❌ plugin-dev.md
❌ doc1.txt
```

### 文档结构

每个文档应包含：

```markdown
# 文档标题

> **简短描述文档内容和用途**

---

## 📋 目录（可选）

1. [章节一](#章节一)
2. [章节二](#章节二)

---

## 章节一

内容...

---

## 章节二

内容...

---

## 相关文档

- [相关文档1](相关文档1.md)
- [相关文档2](相关文档2.md)

---

**最后更新**: 2025-01-31  
**适用版本**: PanSou v1.0+  
**文档状态**: ✅ 已完善
```

### 内容规范

- ✅ 使用清晰的标题层级
