# PanSou 官方服务连接指南

本指南将帮助你配置 PanSou MCP 服务连接到官方的远程 API 服务 `https://so.252035.xyz/`。

## 🎯 配置步骤

### 1. 准备工作

确保你已经：
- ✅ 安装了 Node.js (版本 >= 18.0.0)
- ✅ 克隆了 PanSou 项目到本地
- ✅ 获得了官方服务的账号和密码

### 2. 构建 TypeScript MCP 服务

```bash
# 进入 TypeScript 目录
cd typescript

# 安装依赖
npm install

# 构建项目
npm run build
```

### 3. 配置 MCP 服务

#### 方式一：使用专用配置文件（推荐）

使用项目根目录下的 `mcp-config-remote.json` 文件：

```json
{
  "mcpServers": {
    "pansou-remote": {
      "command": "node",
      "args": [
        "你的项目路径\\typescript\\dist\\index.js"
      ],
      "env": {
        "PANSOU_SERVER_URL": "https://so.252035.xyz",
        "REQUEST_TIMEOUT": "60",
        "MAX_RESULTS": "100",
        "AUTO_START_BACKEND": "false",
        "DOCKER_MODE": "false",
        "ENABLE_IDLE_SHUTDOWN": "false",
        "AUTH_ENABLED": "true",
        "AUTH_USERNAME": "admin",
        "AUTH_PASSWORD": "你的密码"
      }
    }
  }
}
```

**重要配置说明**：
- `PANSOU_SERVER_URL`: 设置为官方服务地址
- `AUTO_START_BACKEND`: 设置为 `false`，不启动本地后端
- `AUTH_ENABLED`: 设置为 `true`，启用认证
- `AUTH_USERNAME` 和 `AUTH_PASSWORD`: 填入你的账号密码

#### 方式二：修改现有配置

如果你想修改现有的 `mcp-config.json`，参考上面的配置进行相应修改。

### 4. 在 Cherry Studio 中配置

1. 打开 Cherry Studio
2. 进入设置 → MCP
3. 选择"添加服务器" → "从JSON导入"
4. 复制 `mcp-config-remote.json` 的内容并导入
5. 确保将路径替换为你的实际项目路径

### 5. 测试连接

配置完成后，在 Cherry Studio 中：

1. 启用 PanSou MCP 服务
2. 尝试发送测试消息：
   ```
   帮我搜索"速度与激情"
   ```
3. 如果配置正确，应该能看到搜索结果

## 🔧 配置参数详解

### 核心参数

| 参数 | 值 | 说明 |
|------|----|----|
| `PANSOU_SERVER_URL` | `https://so.252035.xyz` | 官方服务地址 |
| `REQUEST_TIMEOUT` | `60` | 请求超时时间（秒） |
| `MAX_RESULTS` | `100` | 最大搜索结果数 |

### 后端管理参数

| 参数 | 值 | 说明 |
|------|----|----|
| `AUTO_START_BACKEND` | `false` | 不启动本地后端服务 |
| `DOCKER_MODE` | `false` | 不使用Docker模式 |
| `ENABLE_IDLE_SHUTDOWN` | `false` | 不启用空闲关闭 |

### 认证参数

| 参数 | 值 | 说明 |
|------|----|----|
| `AUTH_ENABLED` | `true` | 启用认证功能 |
| `AUTH_USERNAME` | `admin` | 你的用户名 |
| `AUTH_PASSWORD` | `你的密码` | 你的密码 |

## 🚨 注意事项

### 安全提醒
- ⚠️ 配置文件中包含密码，请妥善保管
- ⚠️ 不要将包含密码的配置文件提交到版本控制系统
- ⚠️ 定期更换密码以确保安全

### 网络要求
- 🌐 确保网络能访问 `https://so.252035.xyz`
- 🌐 如果网络不稳定，可以适当增加 `REQUEST_TIMEOUT` 值

### 使用限制
- 📊 官方服务可能有访问频率限制，请合理使用
- 📊 建议不要过于频繁地发起搜索请求

## 🛠️ 故障排除

### 连接失败
如果出现连接错误：

1. **检查网络连接**
   ```bash
   curl https://so.252035.xyz/api/health
   ```

2. **检查认证信息**
   - 确认用户名和密码正确
   - 检查账号是否被锁定

3. **检查配置文件**
   - 确认路径正确
   - 确认JSON格式正确

### 认证失败
如果出现认证错误：

1. **验证账号密码**
   - 在浏览器中访问 `https://so.252035.xyz` 手动登录测试
   - 确认账号状态正常

2. **检查配置**
   - 确认 `AUTH_ENABLED` 为 `true`
   - 确认用户名密码配置正确

### 搜索无结果
如果搜索没有返回结果：

1. **检查关键词**
   - 尝试使用不同的搜索关键词
   - 确认关键词不为空

2. **检查服务状态**
   - 使用健康检查工具确认服务正常
