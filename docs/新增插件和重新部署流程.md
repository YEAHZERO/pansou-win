## 概述

### 什么时候需要新增插件？

- ✅ 发现了新的网盘资源搜索网站
- ✅ 现有插件不满足需求
- ✅ 想要支持特定的资源类型

### 新增插件的完整流程

```
阶段一：准备工作 (10-30分钟)
  1. 分析目标网站
  2. 确定技术方案
  ↓
阶段二：开发插件 (30-60分钟)
  3. 创建插件文件
  4. 实现搜索逻辑
  5. 本地测试
  ↓
阶段三：集成配置 (5分钟)
  6. 注册插件
  7. 配置启用
  ↓
阶段四：编译部署 (10-20分钟)
  8. 编译项目
  9. 重新部署
  10. 生产验证
```

**总耗时**: 约 1-2 小时（首次开发）

## 新增插件完整流程

### 阶段一：准备工作（10-30分钟）

#### 步骤 1: 分析目标网站

**目标**: 了解网站的数据获取方式和API结构


##### 1.1 访问目标网站

```
示例：https://www.pioz.cn/
```

##### 1.2 判断网站类型

| 类型 | 特征 | 处理方式 |
|------|------|----------|
| **JSON API** | 返回 JSON 数据 | 直接解析 JSON |
| **HTML 页面** | 返回完整 HTML | 使用 goquery 解析 |
| **前端渲染** | 初始 HTML 很少 | 查找 JavaScript API |

##### 1.3 使用浏览器开发者工具（⭐ 最重要）

**操作步骤**：

```
1. 打开目标网站的搜索页面
   例如：https://www.pioz.cn/search

2. 按 F12 打开开发者工具

3. 切换到 "Network"（网络）标签

4. 在网站上执行一次搜索
   例如：搜索 "测试"

5. 在 Network 标签中查看请求
   - 筛选 XHR/Fetch 请求
   - 找到包含搜索结果的请求

6. 点击请求查看详情
   - Request URL: API 端点
   - Request Method: GET/POST
   - Query String: 请求参数
   - Response: 响应数据格式
```

**示例分析结果**：

```
请求 URL: https://example.com/api/search?q=测试&page=1
请求方法: GET
响应格式: JSON

响应示例:
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": "123",
      "title": "资源标题",
      "url": "https://pan.quark.cn/s/xxxxx",
      "password": "1234",
      "create_time": "2025-01-31 10:00:00"
    }
  ],
  "total": 100
}
```

#### 步骤 2: 确定技术方案

根据分析结果选择实现方式：

| 网站类型 | 实现方式 | 参考插件 |
|----------|----------|----------|
| JSON API | 直接 HTTP 请求 + JSON 解析 | miaoso, zhizhen |
| HTML 页面 | HTTP 请求 + goquery 解析 | labi, huban |
| 前端渲染 | 双模式（JSON + HTML） | pioz |

**推荐方案**：实现双模式解析（最稳定）

```go
// 先尝试 JSON
var apiResp APIResponse
if err := json.Unmarshal(body, &apiResp); err == nil {
    // JSON 成功
    return parseJSON(apiResp)
} else {
    // 降级到 HTML
    return parseHTML(body)
}
```

##### 4.1 基础结构（复制模板）

```go
package 插件名

import (
	"context"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"regexp"
	"strings"
	"sync"
	"time"

	"github.com/PuerkitoBio/goquery"
	"pansou/model"
	"pansou/plugin"
	"pansou/util/json"
)

// 预编译正则表达式
var (
	quarkLinkRegex = regexp.MustCompile(`https?://pan\.quark\.cn/s/[0-9a-zA-Z]+`)
	passwordRegex = regexp.MustCompile(`(?:提取码|密码)[：:]\s*([a-zA-Z0-9]{4})`)
	searchResultCache = sync.Map{}
	cacheTTL = 1 * time.Hour
)

// 注册插件
func init() {
	plugin.RegisterGlobalPlugin(New插件名Plugin())
	go startCacheCleaner()
}

func startCacheCleaner() {
	ticker := time.NewTicker(1 * time.Hour)
	defer ticker.Stop()
	for range ticker.C {
		searchResultCache = sync.Map{}
	}
}

// 常量配置
const (
	WebsiteURL     = "https://example.com"
	SearchURL      = "https://example.com/search"
	DefaultTimeout = 10 * time.Second
	MaxRetries     = 3
)

// 插件结构
type 插件名AsyncPlugin struct {
	*plugin.BaseAsyncPlugin
	timeout         time.Duration
	retries         int
	optimizedClient *http.Client
}

// 创建插件实例
func New插件名Plugin() *插件名AsyncPlugin {
	return &插件名AsyncPlugin{
		BaseAsyncPlugin: plugin.NewBaseAsyncPlugin("插件名", 3),
		timeout:         DefaultTimeout,
		retries:         MaxRetries,
		optimizedClient: createOptimizedHTTPClient(),
	}
}

// 创建优化的 HTTP 客户端
func createOptimizedHTTPClient() *http.Client {
	transport := &http.Transport{
		MaxIdleConns:        200,
		MaxIdleConnsPerHost: 50,
		MaxConnsPerHost:     100,
		IdleConnTimeout:     90 * time.Second,
		DisableKeepAlives:   false,
	}
	return &http.Client{Transport: transport, Timeout: DefaultTimeout}
}
```

##### 4.2 实现搜索接口

```go
// 搜索接口（兼容性）
func (p *插件名AsyncPlugin) Search(keyword string, ext map[string]interface{}) ([]model.SearchResult, error) {
	result, err := p.SearchWithResult(keyword, ext)
	if err != nil {
		return nil, err
	}
	return result.Results, nil
}

// 搜索接口（推荐）
func (p *插件名AsyncPlugin) SearchWithResult(keyword string, ext map[string]interface{}) (model.PluginSearchResult, error) {
	return p.AsyncSearchWithResult(keyword, p.doSearch, p.MainCacheKey, ext)
}
```

##### 4.3 实现核心搜索逻辑

```go
func (p *插件名AsyncPlugin) doSearch(client *http.Client, keyword string, ext map[string]interface{}) ([]model.SearchResult, error) {
	// 1. 检查缓存
	if cached, ok := searchResultCache.Load(keyword); ok {
		cachedResp := cached.(cachedResponse)
		if time.Since(cachedResp.timestamp) < cacheTTL {
			return cachedResp.results, nil
		}
	}

	// 2. 使用优化的客户端
	if p.optimizedClient != nil {
		client = p.optimizedClient
	}

	// 3. 构建搜索 URL
	searchURL := fmt.Sprintf("%s?q=%s", SearchURL, url.QueryEscape(keyword))

	// 4. 创建带超时的上下文
	ctx, cancel := context.WithTimeout(context.Background(), p.timeout)
	defer cancel()

	// 5. 创建请求
	req, err := http.NewRequestWithContext(ctx, "GET", searchURL, nil)
	if err != nil {
		return nil, fmt.Errorf("[%s] 创建请求失败: %w", p.Name(), err)
	}

	// 6. 设置请求头（⭐ 重要：避免反爬虫）
	req.Header.Set("User-Agent", "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36")
	req.Header.Set("Accept", "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8")
	req.Header.Set("Accept-Language", "zh-CN,zh;q=0.9,en;q=0.8")
	req.Header.Set("Connection", "keep-alive")
	req.Header.Set("Referer", WebsiteURL)

	// 7. 发送请求（带重试）
	resp, err := p.doRequestWithRetry(req, client)
	if err != nil {
		return nil, fmt.Errorf("[%s] 搜索请求失败: %w", p.Name(), err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != 200 {
		return nil, fmt.Errorf("[%s] 状态码: %d", p.Name(), resp.StatusCode)
	}

	// 8. 读取响应
	respBody, err := io.ReadAll(resp.Body)
	if err != nil {
		return nil, fmt.Errorf("[%s] 读取失败: %w", p.Name(), err)
	}

	// 9. 双模式解析
	var results []model.SearchResult
	var apiResp APIResponse
	if err := json.Unmarshal(respBody, &apiResp); err == nil && apiResp.Code == 200 {
		results = p.convertAPIResults(apiResp.Data, keyword)
	} else {
		results, err = p.parseHTMLResults(respBody, keyword)
		if err != nil {
			return nil, fmt.Errorf("[%s] 解析失败: %w", p.Name(), err)
		}
	}

	// 10. 缓存结果
	searchResultCache.Store(keyword, cachedResponse{
		results:   results,
		timestamp: time.Now(),
	})

	// 11. 关键词过滤
	return plugin.FilterResultsByKeyword(results, keyword), nil
}
```

**详细说明请参考**: [插件开发指南.md](插件开发指南.md)

## 常见问题

### Q1: 编译失败 "go: command not found"

**原因**: Go 环境未配置

**解决方案**：
```batch
REM 1. 检查 Go 是否安装
go version

REM 2. 如果未安装，下载安装
REM https://golang.org/dl/

REM 3. 验证环境变量
echo %GOPATH%
echo %GOROOT%
```

### Q2: 编译失败 "cannot find package"

**原因**: 依赖未下载

**解决方案**：
```batch
REM 1. 下载依赖
go mod download

REM 2. 或设置代理
go env -w GOPROXY=https://goproxy.cn,direct

REM 3. 清理缓存重试
go clean -modcache
go mod download
```

### Q3: 插件不生效

**原因**: 未正确注册或配置

**检查清单**：
```batch
REM 1. 检查 main.go 是否导入
findstr "plugin/插件名" main.go

REM 2. 检查 start.bat 是否启用
findstr "插件名" start.bat

REM 3. 重新编译
go build -o pansou.exe

REM 4. 查看启动日志
REM 确认插件已加载
```

### Q4: 插件搜索无结果

**原因**: API 变化或解析错误

**调试步骤**：
```
1. 使用浏览器开发者工具重新分析网站
2. 检查 API 端点是否变化
3. 检查响应格式是否变化
4. 添加日志输出调试
5. 更新插件代码
```

### Q5: 部署后服务无法启动

**原因**: 端口占用或权限问题

**解决方案**：
```batch
REM 1. 检查端口占用
netstat -an | findstr :8889

REM 2. 结束占用进程
taskkill /F /PID <进程ID>

REM 3. 以管理员身份运行
REM 右键 -> 以管理员身份运行

REM 4. 检查防火墙
REM 添加 pansou.exe 到防火墙例外
```
