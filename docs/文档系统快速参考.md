## 🔄 自动更新机制

### 触发条件

```
主目录创建文档 → 自动移动到 docs → 自动归类 → 更新 README.md
docs 创建文档 → 自动归类 → 更新 README.md
修改文档 → 重新扫描 → 更新 README.md
```

### Hook 配置

| Hook | 触发事件 | 功能 |
|------|----------|------|
| `move-docs-to-folder.json` | 主目录创建文档 | 自动移动到 docs |
| `update-docs-readme-on-create.json` | docs 创建文档 | 自动归类 |
| `update-docs-readme.json` | 文档修改 | 更新索引 |

**位置**: `.kiro/hooks/`

```batch

# 1. Hook 检测到文件创建
# 2. 自动归类
# 3. 更新 README.md
```


## 🆘 故障排除

### 问题 1: 文档未自动移动

**解决**:
```batch
# 检查 Hook 配置
type .kiro\hooks\move-docs-to-folder.json

# 手动移动
move 文档.md docs\文档.md
```

### 问题 2: 索引未更新

**解决**:
```batch
# 手动触发更新
update-docs-index.bat

# 或在 Kiro 中执行更新命令
```

### 问题 3: 分类错误

**解决**:
```batch
# 手动编辑 README.md
notepad docs\README.md

# 调整文档分类
```
