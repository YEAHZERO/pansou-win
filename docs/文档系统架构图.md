## 🔄 自动化工作流程

### 流程 0: 主目录文档自动移动 ⭐

```
┌─────────────────────────────────────────────────────────────┐
│                  用户在主目录创建文档                        │
│                     新功能说明.md                            │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                    Kiro Hook 触发                            │
│            .kiro/hooks/move-docs-to-folder.json             │
│                   Event: fileCreated                         │
│                   Pattern: *.md, *.txt                       │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                    Kiro Agent 处理                           │
│  1. 检查文件名                                               │
│     - 是否为 README.md？→ 跳过                              │
│     - 是否为 LICENSE？→ 跳过                                │
│     - 是否为 CHANGELOG.md？→ 跳过                           │
│  2. 确认为普通文档文件                                       │
│  3. 读取文件内容                                             │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                   移动文件到 docs                            │
│  1. 复制文件到 docs/新功能说明.md                            │
│  2. 验证复制成功                                             │
│  3. 删除主目录下的原文件                                     │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                  触发自动归类流程                            │
│  （调用 update-docs-readme-on-create.json）                 │
│  1. 分析文档内容                                             │
│  2. 判断所属分类                                             │
│  3. 更新 docs/README.md                                      │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                        完成                                  │
│  ✅ 文件已移动到 docs 目录                                   │
│  ✅ 已自动归类并更新索引                                     │
│  ✅ 通知用户：文件已移动到 docs/新功能说明.md                │
└─────────────────────────────────────────────────────────────┘
```

### 流程 1: 新增文档自动归类

```
┌─────────────────────────────────────────────────────────────┐
│                      用户创建新文档                          │
│                   docs/新功能说明.md                         │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                    Kiro Hook 触发                            │
│         .kiro/hooks/update-docs-readme-on-create.json       │
│                   Event: fileCreated                         │
│                   Pattern: docs/*.md                         │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                    Kiro Agent 处理                           │
│  1. 读取新文档内容                                           │
│  2. 分析标题和内容                                           │
│  3. 识别关键词                                               │
│     - "插件" → 插件开发                                      │
│     - "安装" → 安装部署                                      │
│     - "配置" → 配置和使用                                    │
│     - "案例" → 插件案例                                      │
│  4. 判断所属分类                                             │
│  5. 设置推荐指数                                             │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                   更新 docs/README.md                        │
│  1. 在对应分类表格中添加新文档                               │
│  2. 更新文档统计（总数 +1）                                  │
│  3. 在更新记录中添加说明                                     │
│  4. 保持格式和结构不变                                       │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                        完成                                  │
│              新文档已自动归类并更新索引                      │
└─────────────────────────────────────────────────────────────┘
```

### 流程 2: 修改文档自动更新

```
┌─────────────────────────────────────────────────────────────┐

│  1. 扫描 docs 目录所有文档                                   │

                         │
                         ▼

│                   更新 docs/README.md                        │
│  1. 更新文档分类表格                                         │
│  2. 更新场景导航（如果需要）                                 │
│  3. 更新文档统计                                             │
│  4. 更新更新记录                                             │
│  5. 保持格式和结构不变                                       │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│                        完成                                  │
│                  文档索引已自动更新                          │
└─────────────────────────────────────────────────────────────┘
```
