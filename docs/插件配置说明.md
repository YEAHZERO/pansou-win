# PanSou 插件配置说明

## 插件类型概览

PanSou 的插件分为两大类：

### 1. 简单插件（无需配置）
这类插件直接爬取公开网站，无需登录或配置，开箱即用。

**示例**：labi, zhizhen, shandian, duoduo, muou, wanou, hunhepan, jikepan, pansearch, panta, qupansou, hdr4k, pan666, susu, thepiratebay, xuexizhinan, panyq, ouge, huban 等

**特点**：
- ✅ 无需任何配置
- ✅ 在 `start.bat` 中添加到 `ENABLED_PLUGINS` 即可使用
- ✅ 自动搜索公开资源

### 2. 高级插件（需要配置）
这类插件需要登录账号或配置参数，提供更丰富的搜索结果。

**示例**：gying, qqpd, weibo

---

## 简单插件配置方法

### 在 start.bat 中启用

只需在 `ENABLED_PLUGINS` 中添加插件名称即可：

```batch
set ENABLED_PLUGINS=labi,zhizhen,shandian,duoduo,muou,wanou,hunhepan,jikepan,pansearch,panta,qupansou,hdr4k,pan666,susu,thepiratebay,xuexizhinan,panyq,ouge,huban
```

### 插件工作原理

以 **labi** 插件为例：

```go
// 1. 插件自动注册
func init() {
    plugin.RegisterGlobalPlugin(NewLabiPlugin())
}

// 2. 创建插件实例
func NewLabiPlugin() *LabiAsyncPlugin {
    return &LabiAsyncPlugin{
        BaseAsyncPlugin: plugin.NewBaseAsyncPlugin("labi", 1),
        optimizedClient: createOptimizedHTTPClient(),
    }
}

// 3. 实现搜索逻辑
func (p *LabiAsyncPlugin) searchImpl(client *http.Client, keyword string, ext map[string]interface{}) ([]model.SearchResult, error) {
    // 构建搜索URL
    searchURL := fmt.Sprintf("http://xiaocge.fun/index.php/vod/search/wd/%s.html", url.QueryEscape(keyword))
    
    // 发送HTTP请求
    resp, err := client.Get(searchURL)
    
    // 解析HTML页面
    doc, err := goquery.NewDocumentFromReader(resp.Body)
    
    // 提取搜索结果
    doc.Find(".module-search-item").Each(func(i int, s *goquery.Selection) {
        // 提取标题、链接、图片等信息
        result := p.parseSearchItem(s, keyword)
        results = append(results, result)
    })
    
    return results, nil
}
```

**关键点**：
- 插件名称：`"labi"`（在 `ENABLED_PLUGINS` 中使用）
- 优先级：`1`（数字越小优先级越高）
- 搜索目标：`http://xiaocge.fun` 网站
- 返回结果：包含标题、链接、图片等信息的 `SearchResult` 数组

## 高级插件配置方法

### 1. gying 插件（光影资源搜索）

**功能**：搜索光影网站的影视资源

**配置步骤**：

#### 步骤1：启用插件
```batch
set ENABLED_PLUGINS=gying,其他插件...
```

#### 步骤2：启动服务后访问配置页面
```
http://localhost:8888/gying/你的用户名
```

#### 步骤3：在网页上登录
1. 输入光影网站的用户名和密码
2. 点击"登录"按钮
3. 登录成功后，插件会自动保存登录状态

#### 步骤4：测试搜索
在配置页面的"测试搜索"区域输入关键词测试

**工作原理**：
```go
// 1. 提供Web管理界面
func (p *GyingPlugin) RegisterWebRoutes(router *gin.RouterGroup) {
    gying := router.Group("/gying")
    gying.GET("/:param", p.handleManagePage)      // 显示配置页面
    gying.POST("/:param", p.handleManagePagePOST) // 处理登录等操作
}

// 2. 使用 cloudscraper 绕过反爬虫
scraper, err := cloudscraper.New()

// 3. 登录并保存Cookie
scraper, cookie, err := p.doLogin(username, password)
user.Cookie = cookie
user.Status = "active"

// 4. 使用登录状态搜索
results := p.searchWithScraper(keyword, scraper, user)
```

**特点**：
- ✅ 支持多账号（最多10个）
- ✅ 自动保存登录状态（121天有效期）
- ✅ 绕过反爬虫机制
- ✅ Web界面管理

### 2. qqpd 插件（QQ频道搜索）

**功能**：搜索QQ频道中的资源分享

**配置步骤**：

#### 步骤1：启用插件
```batch
set ENABLED_PLUGINS=qqpd,其他插件...
```

#### 步骤2：访问配置页面
```
http://localhost:8888/qqpd/你的QQ号
```

#### 步骤3：扫码登录
1. 页面会显示QQ登录二维码
2. 使用手机QQ扫描二维码
3. 扫码后自动检测登录状态

#### 步骤4：配置频道列表
在"频道管理"区域添加QQ频道号，每行一个：
```
pd97631607
kuake12345
languan8K115
```

#### 步骤5：保存并测试
点击"保存频道配置"，然后在"测试搜索"区域测试

**工作原理**：
```go
// 1. 生成QQ登录二维码
qrcodeBytes, qrsig, err := p.generateQRCodeWithSig()

// 2. 轮询检查登录状态
loginResult, err := p.checkQRLoginStatus(user.Qrsig)

// 3. 登录成功后保存Cookie
user.Cookie = loginResult.Cookie
user.Status = "active"

// 4. 搜索QQ频道
for _, channelID := range user.Channels {
    results := p.searchChannel(channelID, user.Cookie, keyword)
}
```

**特点**：
- ✅ 支持多账号（最多10个）
- ✅ 扫码登录，安全便捷
- ✅ 支持多个频道（自动去重）
- ✅ 智能分配任务到不同账号

## 插件数据存储

### 简单插件
- 无需存储用户数据
- 只使用内存缓存搜索结果

### 高级插件
所有高级插件的用户数据都存储在：
```
{CACHE_PATH}/插件名_users/
```

例如：
- gying: `cache/gying_users/`
- qqpd: `cache/qqpd_users/`
- weibo: `cache/weibo_users/`

每个用户一个JSON文件，包含：
- 登录状态
- Cookie
- 配置信息（频道列表、用户ID列表等）
- 有效期

**示例**（gying用户数据）：
```json
{
  "hash": "abc123...",
  "username": "user123",
  "username_masked": "u***3",
  "encrypted_password": "...",
  "cookie": "session=...; token=...",
  "status": "active",
  "created_at": "2026-01-31T10:00:00Z",
  "login_at": "2026-01-31T10:00:00Z",
  "expire_at": "2026-05-31T10:00:00Z",
  "last_access_at": "2026-01-31T12:00:00Z"
}
```

## 插件优先级

插件优先级决定搜索结果的排序，数字越小优先级越高：

```go
plugin.NewBaseAsyncPlugin("labi", 1)      // 优先级 1（最高）
plugin.NewBaseAsyncPlugin("gying", 3)     // 优先级 3
plugin.NewBaseAsyncPlugin("qqpd", 3)      // 优先级 3
plugin.NewBaseAsyncPlugin("weibo", 3)     // 优先级 3
```

在搜索结果中，优先级高的插件结果会排在前面。

## 常见问题

### Q1: 如何查看已启用的插件？

**A**: 访问健康检查接口：
```bash
curl http://localhost:8888/api/health
```

响应示例：
```json
{
  "status": "ok",
  "plugins_enabled": true,
  "plugin_count": 31,
  "plugins": ["labi", "zhizhen", "gying", "qqpd", "weibo", ...]
}
```

### Q2: 高级插件登录失败怎么办？

**A**: 
1. 检查网络连接
2. 刷新二维码重新扫描
3. 查看服务器日志：`DebugLog = true`
4. 确认账号密码正确（gying）

### Q3: 如何禁用某个插件？

**A**: 从 `ENABLED_PLUGINS` 中移除插件名称，然后重启服务。

### Q4: 插件搜索结果为空？

**A**: 可能原因：
1. 关键词不匹配
2. 目标网站无相关资源
3. 高级插件未登录或登录已过期
4. 网站结构变化导致解析失败

### Q5: 如何开发自定义插件？

**A**: 参考 [插件开发指南](插件开发指南.md)
