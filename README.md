## 项目简介

PanSou 是一个强大的网盘搜索聚合系统，支持多种搜索源和插件扩展。采用纯 Go 语言实现，提供高性能的搜索服务和灵活的插件机制。

### 主要作用

**核心功能**：
1. **多源聚合搜索**
   - Telegram 频道搜索（通过 t.me API）
   - 网站插件搜索（支持80+个网盘搜索网站）
   - 智能结果合并与去重

2. **高性能缓存系统**
   - 两级缓存（内存 + 磁盘）
   - 智能批量写入
   - 异步更新机制

3. **插件化架构**
   - 支持动态注册插件
   - 异步搜索机制（4秒响应超时）
   - 灵活的优先级配置

4. **RESTful API**
   - 搜索接口（支持GET/POST）
   - 认证系统（JWT）
   - 健康检查接口

### 技术栈

- **语言**: Go 1.24+
- **Web框架**: Gin
- **HTML解析**: goquery
- **JSON处理**: sonic (高性能)
- **认证**: JWT
- **缓存**: 自研两级缓存系统

### 核心特性

- ✅ 多源聚合搜索（Telegram 频道 + 网站插件）
- ✅ 插件化架构，易于扩展
- ✅ 高性能缓存机制
- ✅ RESTful API 接口
- ✅ 纯 Go 实现，源码编译部署
- ✅ 支持认证和权限控制

| 文档 | 说明 | 推荐指数 |

**系统架构概览**：

#### 搜索流程
```
用户请求 → API Handler → SearchService
           ↓
    并行搜索 TG + 插件
           ↓
    结果合并 + 去重 + 排序
           ↓
    按网盘类型分组
           ↓
    返回 JSON 响应
```

#### 缓存机制
**两级缓存架构**:
- **内存缓存**: 快速访问，容量有限
- **磁盘缓存**: 持久化存储，容量大
- **智能批量写入**: 减少磁盘IO，提升性能
- **异步更新**: 不阻塞主流程

**缓存键生成规则**:
```
TG搜索: tg:关键词:频道1,频道2
插件搜索: plugin:关键词:插件1,插件2
```

#### 异步插件系统
**工作原理**:
1. 插件注册到全局注册表
2. 搜索时并发调用多个插件
3. 4秒响应超时（可配置）
4. 超时后后台继续处理
5. 结果通过缓存异步更新

**优势**:
- 快速响应用户请求
- 充分利用多核CPU
- 避免慢插件拖累整体性能

#### 结果排序算法
**综合评分 = 时间得分 + 关键词得分 + 插件等级得分**

- **时间得分**: 越新越高（最高500分）
  - 1天内: 500分
  - 3天内: 400分
  - 1周内: 300分
  - 1月内: 200分

- **关键词得分**: 包含"合集"、"系列"等优先（最高400分）

- **插件等级得分**: 
  - 等级1: 1000分（最高质量插件，如pioz）
  - 等级2: 500分（高质量插件）
  - 等级3: 0分（普通插件）
  - 等级4: -200分（低质量插件）

#### 目录结构
```
pansou/
├── main.go              # 程序入口
├── config/              # 配置管理
│   └── config.go
├── api/                 # API层
│   ├── router.go        # 路由配置
│   ├── handler.go       # 请求处理
│   ├── middleware.go    # 中间件
│   └── auth_handler.go  # 认证处理
├── service/             # 业务逻辑层
│   └── search_service.go
├── model/               # 数据模型
│   ├── request.go
│   ├── response.go
│   └── plugin_result.go
├── plugin/              # 插件系统
│   ├── plugin.go        # 插件基础框架
│   ├── pioz/            # pioz插件示例
│   └── ...              # 80+个插件
└── util/                # 工具库
    ├── cache/           # 缓存系统
    ├── pool/            # 工作池
    └── http_util.go     # HTTP工具
```

**配置参数说明**：

#### 基础配置
```batch
set PORT=8889                    # 服务端口
```

#### Telegram频道配置
```batch
set CHANNELS=tgsearchers4,Aliyun_4K_Movies,bdbdndn11
# 多个频道用逗号分隔
```

#### 插件配置
```batch
set ASYNC_PLUGIN_ENABLED=true   # 启用插件功能
set ENABLED_PLUGINS=pioz,labi,zhizhen,shandian,duoduo
# 指定启用的插件，留空则不启用任何插件
```

#### 代理配置（可选）
```batch
set PROXY=socks5://127.0.0.1:7890           # SOCKS5代理
# set PROXY=http://127.0.0.1:7890           # HTTP代理
# set HTTP_PROXY=http://127.0.0.1:7890      # HTTP代理
# set HTTPS_PROXY=http://127.0.0.1:7890     # HTTPS代理
```

#### 缓存配置
```batch
set CACHE_ENABLED=true           # 启用缓存
set CACHE_PATH=./cache           # 缓存目录
set CACHE_MAX_SIZE=300           # 最大缓存大小(MB)
set CACHE_TTL=90                 # 缓存有效期(分钟)
```

#### 性能配置
```batch
set CONCURRENCY=25               # 并发数（自动计算：频道数+插件数+10）
set ASYNC_RESPONSE_TIMEOUT=4     # 异步响应超时(秒)
set PLUGIN_TIMEOUT=30            # 插件超时(秒)
set GC_PERCENT=50                # GC触发阈值
set OPTIMIZE_MEMORY=true         # 内存优化
```

#### 认证配置（可选）
```batch
set AUTH_ENABLED=true            # 启用认证
set AUTH_USERS=admin:password123,user:pass456
# 格式：用户名:密码，多个用户用逗号分隔
set AUTH_TOKEN_EXPIRY=24         # Token有效期(小时)
```
